ee5.net

ee5.net is a hodge-podge of loosely related personal stuff. Mostly my cats, with ships and ports, a couple of squirrels, a jazz funk band, and me.

The lists below are a nod to the fact that this is hosted on GitHub — why not. Everything above is for everyone else; everything below is more for developers.

Work

  • r1 quick-viewer A fast full-screen directory image viewer. The current one. Rust · iced
  • r2 ee-conio ANSI escape-sequence encoding for terminals. The foundation the rest builds on. Rust · crates.io
  • r3 ee5_util Utility library. C++
  • r4 ee5_base64 base64 encoding. Lua
  • fill github.com/ErnieE5 Everything else, including the forks kept for reading. profile
